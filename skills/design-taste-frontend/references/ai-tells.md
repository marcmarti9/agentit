# AI tells (banned patterns)

Use unless the brief **explicitly** requests the pattern. These are production-tested LLM defaults.

## Visual / CSS

- Neon outer glows and purple/indigo mesh as unprompted brand
- Pure `#000` / pure `#fff` as sole surfaces (prefer off-black / off-white)
- Oversaturated accents without brand reason
- Excessive gradient text on large headers
- Custom mouse cursors
- Three equal feature cards as the only section idea
- Div-built fake product screenshots, fake terminals, fake dashboards
- Broken stock-photo URLs; prefer real assets, generated images, or labeled slots

## Typography

- Inter as automatic default when the brief allows better brand type (override if Linear-neutral / a11y public-sector)
- Serif display as automatic "creative" choice — only for truly editorial/luxury briefs with a named reason
- Injecting a random serif word into a sans headline for "interest"
- Em-dash (`—`) as decoration **or** body habit — use hyphen `-` or rewrite
- Vertical rotated text strips as default agency flair
- Crosshair / decorative grid lines with no content role

## Micro-meta labels

- Version stamps in hero (`v0.6`, `BETA`, `EARLY ACCESS`) unless launch status is the product
- `Brand · No. 01` sub-eyebrows and section indices
- `Scroll · 001` scroll cues with section numbers
- Overuse of middle-dot separators (`a · b · c · d`)
- Status dots on every list item/nav link without real state meaning
- Pills/tags overlaid on images (`Plate · 03`)
- Decorative photo-credit captions on stock placeholders
- Footer build strings on marketing pages (`v1.4.2`, `last sync 4s ago`)
- Weather / locale / clock strips unless place/time is the product

## Copy

- Filler: elevate, seamless, unleash, next-gen, revolutionize, supercharge
- Generic names/avatars (Jane Doe, egg icons) for testimonials
- Fake-perfect metrics (`99.99%`, `10x`) without source or mock label
- Startup-slop brand names (Acme, Nexus, SmartFlow) when inventing examples
- "Quietly trusted by" / performative craftsman labels ("From the field", "On the bench")
- Generic step labels (`Stage 1`, `Phase 01`) instead of verb-noun steps
- Duplicate CTA intents with different wording

## Premium-consumer palette trap

Default warm beige/cream + brass/clay/oxblood is a recurring AI tell for cookware/wellness/DTC. Rotate cold luxury, forest, monochrome+pop, cobalt+cream, terracotta+slate, etc., unless the brand brief names the warm-craft palette.

## shadcn / component kits

Allowed when customized to the design read. Shipping stock shadcn chrome on a marketing site is a tell.
