## Evidence preserved here

- `baseline/`: complete text logs/status from the original clean baseline run plus the source-archive checksum.
- `local/jit-red-tests.log`: audit regressions executed against the frozen baseline and required to fail.
- `local/post-probes.json` and `post-skills-inventory.json`: post-fix probes generated from the current PR source.
- `local/command-receipt.json`: command-bound JIT regression verification generated by the current runtime.
- `final-ci/`: complete text logs/status from the previously verified final remote evidence artifact plus the source-archive checksum.
- `verification-remote.json`: immutable run/artifact/commit identifiers used by the audit.

## Why the old chat ZIPs are not committed

The ZIP/tar files previously attached in chat were derivative convenience packages containing repository source plus these reports/logs. They are not unique source-of-truth artifacts. The repository commit is the canonical source snapshot; this directory preserves the unique text evidence and source archive checksums. The intermediate SEO transport ZIP is also redundant now that PR #54 targets `main` and directly includes the former PR #53 changes.

## Evidence boundary

These files demonstrate the runtime, installation and context-delivery behavior exercised by the tests. They do **not** demonstrate perfect semantic skill selection, model attention/compliance, context erasure, independent-model review or OS-level sandboxing. Those limits remain explicit in the canonical reports and `evals/jit-host-cases.json`.
