# Agentit profile index

Generated by `python3 scripts/build_profile_index.py`; edit `profiles.yaml`, then regenerate. `--check` fails on drift, unknown IDs or canonical skills without a meaningful domain profile.

Profiles are source-neutral availability/discovery maps. Agentit-authored and imported skills share these domains; provenance stays in each source path. Compatibility aliases appear last and never define a second catalog.

Choose profiles from the actual task, inspect metadata, then explicitly select complete bodies. A profile never activates itself. Select a subset by relevance; a whole profile is justified only when every body helps the current stage and the context cost fits. Neither a fixed minimum nor a fixed maximum applies.

Body cost includes inherited skills once per profile. Estimated tokens = UTF-8 bytes / 4, rounded up per body; this is a rough planning heuristic, not a tokenizer count. Supporting references and host instructions add context beyond these estimates.
