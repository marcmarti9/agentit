## Residual content risks

Large upstream bodies remain large when deliberately selected; metadata discovery does not make their loaded text free. Size is measured, not silently truncated. Splitting external packages requires a separate provenance-preserving curation decision, not an untested rewrite of every specialist.

Hallmark links `../../site/css/tokens.css`, `../../docs/recipes.md` and `../../docs/study-examples.md` refer outside its vendored package and are absent locally. The package retains its original links/provenance. Use current upstream evidence when needed and report unread material; a missing reference cannot pass schema-3 material-reference validation. This is a disclosed residual source-packaging limitation, not repaired by inventing local files.

Provider-specific API examples, prices, legal/financial assertions, tool availability and marketing claims still require current primary-source verification when used. This audit verifies the delivery and integration layer, not eternal correctness of an external knowledge corpus.
