# Google Business Profile

El GBP es el activo #1.

## Setup a prueba de suspension

- Nombre = LLC / DBA. Keyword stuffing en el nombre = suspension.
- Direccion real. Virtual offices y PO boxes se caen. Cartel + verifica.
- Workspace de empresa antes de crear el perfil.
- No cambies nombre + direccion + categoria la misma semana.
- Carpeta de appeal: LLC, factura, licencia, fotos del rotulo.
- Nunca 100% del negocio en un solo perfil.

## Categoria y exact match

Copia la categoria primaria de los 3 que ya estan arriba.
Nombre alineado a servicio + ciudad (DBA legal) gana a 5x reviews.
Exact-match domain solo con site vivo. Redirect no hace magia.

## Completar

- Descripcion 750 caracteres, keyword + zonas + CTA.
- Products rellenos aunque vendas servicio.
- Fotos/videos reales cada semana.
- Updates semanales con keyword + ciudad.
- FAQ en la web (Google mato el Q&A del perfil).

## Multi-pin

Siguiente pin si: no rankeas alli, clientes ricos, reviews manejables, puedes servir el area, el alquiler se justifica.

## SAB

Default no. Excepcion: mercado pequeno y rico + exact-match GBP + domain vivo + reviews altas + 20-30 links.
