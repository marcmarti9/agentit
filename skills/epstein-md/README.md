# epstein-md

Strict anti-AI-slop design skill for Agentit.

Inspired by the principles described in [epstein.md by shipper.now](https://x.com/shipper_now/status/2110637576935891122):

- no box shadows
- no emojis
- no LIVE badges
- 0 blue/purple gradients
- ignore the most common AI words

Use it on any frontend or visual interface work.
